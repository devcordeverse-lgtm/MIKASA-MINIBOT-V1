</div>🌸 ABOUT MIKASA

MIKASA MINI BOT is a modern WhatsApp Multi-Device Bot designed to make your WhatsApp experience easier, faster and more enjoyable.

⚡ FEATURES

- 🤖 Multi-Device Support
- 🎵 Music Commands
- 🎬 Video Downloads
- 🖼️ Sticker Maker
- 🛡️ Group Management
- ⚙️ Advanced Settings
- 📥 Media Downloader
- ✨ Automatic Features

🚀 INSTALLATION

git clone YOUR_REPOSITORY_LINK
cd MIKASA-MINI-BOT
npm install
npm start

🔑 CONFIGURATION

BOT_NAME=MIKASA MINI BOT
PREFIX=.
OWNER_NAME=CODEVERSE

💻 REQUIREMENTS

- Node.js 20+
- Git
- Internet Connection
- WhatsApp Account
